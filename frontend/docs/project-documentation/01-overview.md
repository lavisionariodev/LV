# 01 — Overview

**Product:** Lavisionario — Next.js marketplace (buyers, sellers, admins).

**In repo:** Single app under `frontend/` — UI + Route Handlers (`src/app/api/`). Data/auth: **Supabase**. Payments: **PayMongo**.

## Environments

| Env | URL |
|-----|-----|
| Local | `http://localhost:3000` |
| Production | `https://lavisionario.vercel.app` |

## Stack (short)

Next.js ~16 · React 19 · Tailwind 4 · Supabase (Auth + Postgres) · PayMongo · Nodemailer (SMTP) · next-pwa (off in dev)
